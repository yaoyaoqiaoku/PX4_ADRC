# ADRC 真机硬化参数：仿真测试指南（v3）

> 日期：2026-08-13
> 适用范围：FLT / NF / NBW / TAU / Z3MAX / FF / KI / RAMP 共 8 个参数的仿真验证方法

---

## 0. 结论先行

这些参数在**默认 SITL 里大部分测不出效果**——默认仿真对象是理想刚体，没有真机的陀螺噪声、执行器延时和 2~3 Hz 机架柔性模态。所以测试分两层：

1. **控制器级仿真（推荐，本次已搭好）**：直接编译固件里同一份 `Adrc.cpp`，注入真机三大特征（噪声 + 延时 + 柔性模态），逐个参数开关对比。**结论可直接迁移到真机调参。**
2. **PX4 SITL**：只能测 FF/KI/RAMP/Z3MAX 的功能行为；TAU/FLT 可用 SIH 注入延时/噪声后测；NF 无法验证（SITL 没有谐振峰）。

## 1. 控制器级仿真：原理与复现

### 1.1 为什么这样测

真机振荡的机理（2.4~3 Hz 极限环）需要三个要素同时存在：

- **执行器延时**（ESC+14 寸桨 10~30 ms）——ESO 把延时当扰动去补偿；
- **柔性模态**（机臂/桨 2.8 Hz 左右）——补偿回路在此频率增益 >1；
- **陀螺噪声**——耦合进 z3 放大抖动。

控制器级仿真把这三个要素注入单轴对象模型，用**固件编译出的同一份 Adrc.cpp** 跑闭环，就能在桌面上复现极限环并验证每个参数的压制效果。

### 1.2 复现方法

代码在 `work/adrc_param_sim/`（工作区）：

```bash
cd /home/liuyao/文档/Codex/2026-08-13/ardupilot-ap-adrc-adrc-adrc/work/adrc_param_sim
g++ -std=c++11 -O2 -include cfloat -I. \
    -I/home/liuyao/my_px4_project/PX4-Autopilot/src/modules/adrc_rate_control \
    sim_main.cpp /home/liuyao/my_px4_project/PX4-Autopilot/src/modules/adrc_rate_control/Adrc.cpp \
    -o sim_test
./sim_test
```

对象模型（单轴，与真机量级一致）：

```
刚体：        rate_dot = b0·u_act + 扰动
执行器延时：  u_act 一阶滞后（默认 40 ms，可调）
柔性模态：    f'' = -2ζωf' - ω²f + k_f·b0·u_act，ω=2π·2.8Hz，ζ=0.08
测量：        y = rate + f + 白噪声(0.05 rad/s)
```

### 1.3 测试矩阵与结果（ESO_W=40、CW=6 的临界振荡工况）

| 场景 | 速率 std | 2-4Hz 频带 | 峰值 | z3_std | 输出抖动量 | 说明 |
|---|---|---|---|---|---|---|
| A1 baseline（全关） | 2.54° | **38%** | **2.05Hz** | 2.49 | 4.3/s | 复现 2Hz 极限环 |
| A2 +FLT 30Hz | 2.78° | 49% | 3.03Hz | 2.51 | **2.2/s** | 不治谐振，但输出抖动减半 |
| A3 +NF 2.0Hz（对准峰） | **254°** | 0.5% | 1.76Hz | 46 | 19.9/s | **发散！相位滞后更致命** |
| A4 +TAU 0.04s | 3.44° | **10%** | **0.59Hz** | 2.44 | 4.3/s | **极限环消失，回到低频响应** |
| A5 +Z3MAX 40 | 2.54° | 38% | 2.05Hz | 2.49 | 4.3/s | 本工况 z3 未触限，无效果（安全网） |
| A6 +FLT+TAU | 3.52° | 12% | 0.59Hz | 2.44 | 2.2/s | 组合：稳定 + 低抖动 |
| A7 +FLT+TAU+Z3MAX | 3.52° | 12% | 0.59Hz | 2.44 | 2.2/s | 同 A6 |
| A8 +all | 3.95° | 28% | 0.59Hz | 2.45 | 2.0/s | NF 又引入相位滞后，不如 A6 |
| A9 阵风50 Z3MAX=0 | 29.6° | 12% | 0.59Hz | 20.3 | 9.2/s | 大扰动，z3 不饱和 |
| A10 阵风50 Z3MAX=40 | 46.0° | 7% | 0.59Hz | 16.2 | 9.2/s | **z3 触限 1562 次**，限幅生效 |

### 1.4 关键发现（可直接指导真机调参）

1. **TAU 是治极限环的主力**：2-4Hz 频带 38%→10%，峰值 2.05→0.59Hz。这印证了"执行器延时建模对真机稳定性最有效"。
2. **FLT 治抖动不治谐振**：rate_std 几乎不变，但输出抖动量减半。适合配 TAU 用（A6）。
3. **低频 notch 慎用**：即使对准峰值（A3），窄带 notch 的相位滞后也会在临界工况触发发散；放错频率（A3b）更糟。**notch 只作最后手段，且要配合降 CW/ESO_W。**
4. **Z3MAX 是安全网不是调参项**：正常工况不触发；大扰动时确实限制住 z3（A10 zsat=1562），代价是补偿变弱、速率偏差变大。真机保持默认自动 2·b0 即可。
5. **FF 加快响应但引入静差**（见下节 B 组）。

### 1.5 FF / KI / RAMP 的测试结果

**B 组（阶跃响应，sp=1 rad/s）：**

| 场景 | 上升时间 | 稳态误差 |
|---|---|---|
| FF=0 | 0.322s | 0.0016 |
| FF=0.4 | 0.267s（更快） | 0.068（引入静差！） |
| FF=0.4 + KI=0.3 | 0.262s | 0.031（KI 在收敛） |
| FF=0.8 + KI=0.3 | 0.220s | 0.057 |

**发现：当前 FF 实现（u0 = wc·e1 + FF·sp）在恒定速率设定值下会留下静差 e1 = -FF·sp/wc。** 这是比例前馈的固有性质（PX4 原版 PID 靠积分消除），所以 **FF 必须配合 KI 使用**，否则真机定速转弯会有速率偏差。

**C 组（gamma=0.7 + b0 失配 + 常值扰动）：** KI=0.3 将稳态误差从 0.066 降到 0.027 并持续收敛。注意积分权威上限是 0.5（抗饱和设计），残差过大时需提高 KI 或 gamma。

**D 组（输出限速）：** RAMP=0/2/1 时最大输出变化率 26.8/2.0/1.0 s⁻¹，精确生效；上升时间几乎不变（闭环带宽主导）。RAMP 是"最后保险"，防阶跃激励，正常跟手不需要开太小。

## 2. PX4 SITL 里能直接测什么

### 2.1 可以直接测（行为验证）

| 参数 | SITL 测试方法 | 看什么 |
|---|---|---|
| FF | 切 Acro 打杆阶跃，对比 FF=0/0.4/0.8 | 角速率上升更快；但定杆后看 `rate` 与 `setpoint` 的稳态差（静差） |
| KI | 同上开 KI，或故意留安装偏置 | 静差逐渐归零（`listener adrc_status` 的 e1 收敛） |
| RAMP | 打杆阶跃，`listener vehicle_torque_setpoint` | 输出变化斜率被限制（对比 u 的 maxdu） |
| Z3MAX | 悬停中给大风扰动 / 加载，`listener adrc_status` | `z3raw != z3` 说明触限（v3 新增调试字段） |
| 功能 | 全部参数设上飞一圈 | 不炸机、日志正常 |

### 2.2 注入真机特征后测（SIH 模拟器）

PX4 的 `simulator_sih` 自带：

- **执行器延时**：`SIH_T_TAU`（默认 0.05s，可设 0.01~0.04 模拟 14 寸桨）→ 配合 `ADRC_*_TAU` 对比极限环是否出现/消失；
- **陀螺噪声**：SIH 内置（约 0.14/0.07/0.03 rad/s）→ 配合 `ADRC_*_FLT` 对比 z3 抖动和输出平滑度。

SIH 在 SITL 里需要手动启动（`simulator_sih start`），属于硬件在环为主，配置稍繁琐；如果只是验证 TAU/FLT 效果，控制器级仿真（第 1 节）更快更可控。

### 2.3 SITL 测不了的

- **NF 对准谐振**：SITL 的刚体模型没有 2~3 Hz 柔性模态，notch 无物可滤；验证只能在控制器级仿真（已做）或真机（用悬停日志 FFT 找峰）。
- **TAU/FLT 的极限环级效果**：默认 jMAVSim/Gazebo 对象延时和噪声都不足，看不到振荡→压制的完整过程。

## 3. 对真机调参的顺序建议（结合仿真发现）

1. **先 TAU**（0.02s 起步）——这是压极限环的主力；
2. **再 FLT**（30Hz）——配 TAU 减输出抖动；
3. **CW/ESO_W 逐步放开**，每次确认 z3raw 不持续触限；
4. **FF + KI 配对开**（FF 0.3~0.6，KI 0.1~0.3），别单独开 FF；
5. **Z3MAX 保持默认 0（自动 2·b0）**；
6. **NF 最后用**，且只在日志 FFT 有清晰窄峰时对准，同时降带宽；
7. **RAMP 默认 0**，只在打杆激励柔性模态时开 5~20。
