# ADRC 真机优化：底层改进方案（v2，2026-08-13）

## 0. 结论先行

你在真机上遇到的问题**不是“参数没调好”**，而是控制结构在真机上缺了三样东西：

1. **反馈端的噪声/谐振处理** —— ADRC 的 ESO 会把你机架 2.4~3 Hz 的柔性谐振当成“扰动”去补偿，越补越振；
2. **执行器延时建模** —— ESC+14 寸桨有约 10~30 ms 的响应滞后，ESO 把它也当成“扰动”，高带宽下形成正反馈；
3. **ESO 状态约束** —— z3（总扰动估计）没有限幅，谐振时会发散并顶到输出饱和，形成极限环（limit cycle）。

这三件事靠 `CW`、`ESO_W`、`b0` 是调不出来的，必须从算法结构上改。本轮已把这些能力全部加进你的 `adrc_rate_control` 模块，**全部做成可开关参数，默认不影响现有行为**。两块板编译通过，flash 增量仅约 0.2%。

## 1. 真机振荡根因分析（为什么参数调不动）

### 1.1 你看到的“晃动”是什么

日志里 2.4~3 Hz 的振荡，是**闭环极限环**，不是单一机架模态。机理：

- LADRC 的 ESO 认为“控制量 u 立即产生 b0·u 的角加速度”；
- 真机实际是：电调 PWM → 电机转速 → 桨拉力 → 扭矩，中间有延时，还有桨/机臂柔性；
- ESO 把延时和柔性造成的“实际响应 ≠ b0·u”全部归入 z3（总扰动），然后通过 `u = (u0 - z3)/b0` 反向补偿；
- 当 ESO 带宽扫过谐振频率时，这个“补偿回路”在谐振处增益 > 1、相位裕度 < 0，于是 2~3 Hz 振荡被激励出来，且振幅被 z3 发散不断推高，直到输出饱和形成极限环。

### 1.2 为什么“ESO 要 3~5 倍 CW”的规则在真机失效

那条规则的前提是**对象是干净的积分链**（`ẋ = b0·u + f`）。真机在回路上多了延时、谐振、噪声三项，观测器带宽的实际上限由**鲁棒性**决定，不由规则决定。你把 ESO_W 从 18 提到 25，振荡更糟，正是这个原因。

### 1.3 为什么 b0=200 “好像稳一点”

`u = (u0 - z3)/b0`，b0 越大、控制增益越小、回路越迟钝，谐振激励变弱，所以“稳一点”。这是**掩盖问题**，不是解决问题——代价是跟手变差、抗风变差。按你 66 cm 轴距、3.5 kg 的物理参数，真实 b0 约 **90（roll/pitch）、8（yaw）**。

### 1.4 为什么之前 notch “没生效”

之前建议设 `IMU_GYRO_NF0_FRQ`，但日志里它一直是默认的 125，说明参数没真正写进去（可能被覆盖或没保存）。而且 PX4 的 gyro notch 是给高频电机/桨谐振（几十~几百 Hz）用的，2~3 Hz 的低频极限环靠它未必合适。所以本轮在**模块内部**加了一个可调中心频率的反馈 notch，和 PX4 的 gyro notch 独立。

## 3. 本轮已实现的底层改进

全部在 `src/modules/adrc_rate_control/`，参数默认值设计为**不改变现有行为**（FLT/NF/TAU/FF/KI/RAMP 默认 0=关闭；Z3MAX 默认 0=自动限幅 2|b0|，这是保护性的，始终生效）。

### 3.1 反馈低通滤波 `ADRC_*_FLT`（Hz，默认 0=关）

在 ESO 入口对实测角速率做一阶低通。作用：压掉陀螺高频噪声耦合进 z3，让 ESO 只看到“真实运动”。

真机起点：30~50 Hz。

### 3.2 反馈 Notch `ADRC_*_NF` / `ADRC_*_NBW`（Hz，默认 0=关 / 1）

模块内的 biquad 陷波，中心频率可设。用悬停日志角速率 FFT 找到你机架的谐振峰（比如 2.8 Hz），把 NF 设成该频率，NBW 先 1 Hz。

注意：低频 notch 会带来相位滞后，**优先用 TAU + ESO_W 降低解决**，notch 只做最后手段。

### 3.3 执行器延时补偿 `ADRC_*_TAU`（s，默认 0=关）

ESO 输入不再用瞬时 u，而是用一阶延时模型 `u_eso`（时间常数 TAU）：

```
u_eso += dt/(TAU+dt) * (u - u_eso)   # 给 ESO 的输入
```

物理意义：让 ESO 知道“扭矩要 TAU 秒后才真正作用到机体上”，它就不会把延时当成扰动去补偿。这是本轮对真机稳定性**最有效的一项**。14 寸桨、6S：**TAU 起点 0.02 s，范围 0.01~0.03**。

### 3.4 ESO 扰动估计限幅 `ADRC_*_Z3MAX`（rad/s²，默认 0=自动 2|b0|）

z3 是“总扰动角加速度”，物理上不可能超过该轴能产生的最大角加速度（≈ b0）。限幅到 2|b0| 能阻止 ESO 发散和极限环。默认自动限幅，无需配置；若想更紧可手动设（如 60）。

### 3.5 前馈 `ADRC_*_FF`（默认 0=关）

控制律从 `u0 = w_c·e1` 扩展为：

```
u0 = w_c·e1 + FF·rate_setpoint + KI·∫e1 dt
```

前馈解决“低带宽下跟手差”的问题：不用把 CW 拉高（拉高就碰谐振），靠前馈恢复打杆响应。真机起点 0.3~0.6。

### 3.6 积分 `ADRC_*_KI`（默认 0=关）

带抗饱和（条件积分：输出饱和时冻结）。b0 标定有误差或机体有安装偏置时，积分消除静差。真机起点 0.1~0.3，配合 Z3MAX 使用。

### 3.7 输出限速 `ADRC_*_RAMP`（1/s，默认 0=关）

限制归一化扭矩变化率，防止阶跃指令激励柔性模态。谐振顽固时可 5~20。

### 3.8 调试消息扩展

`adrc_status` 新增：

- `y[3]`：经过滤波/notch 后真正喂给 ESO 的反馈（看滤波是否生效）；
- `ueso[3]`：经过 TAU 模型后的 ESO 输入（看延时补偿是否生效）；
- `integ[3]`：积分状态（看 KI 是否在合理范围）。

日志里直接监听 `adrc_status` 即可，无需改地面站。

## 4. 真机调参流程（从底层开始，按顺序，安全）

> 安全第一：每一轮只改一个参数；悬停高度 0.5~1 m；手不离解锁开关；一旦出现 2~4 Hz 振荡立即降落/切回 PID 固件。

### 第 0 步：确认硬件与基准

- 用 PID 固件飞一次悬停 30 s，记录日志；
- 用 `ulog_info`/Python 对 roll/pitch 角速率做 FFT，**记下所有谐振峰**（尤其 2~4 Hz 和电机频率）；
- 这组 PID 日志是“及格线”，后面所有 ADRC 日志和它对比。

### 第 1 步：修正 b0（用物理值，别再拍脑袋）

```
param set ADRC_ROLL_B0 90
param set ADRC_PITCH_B0 90
param set ADRC_YAW_B0 8
```

（按 66 cm 轴距、3.5 kg、14 寸桨估算。更准的做法见第 6 节。）

### 第 2 步：保守带宽起步

```
param set ADRC_ROLL_CW 4
param set ADRC_PITCH_CW 4
param set ADRC_YAW_CW 3
param set ADRC_ROLL_ESO_W 10
param set ADRC_PITCH_ESO_W 10
param set ADRC_YAW_ESO_W 8
```

ESO_W 10 rad/s ≈ 1.6 Hz，**低于**你观测到的 2.4~3 Hz 谐振。这一步的目标是“先稳下来”，不追求跟手。

### 第 3 步：打开结构改进

```
param set ADRC_ROLL_FLT 30
param set ADRC_PITCH_FLT 30
param set ADRC_YAW_FLT 20
param set ADRC_ROLL_TAU 0.02
param set ADRC_PITCH_TAU 0.02
param set ADRC_YAW_TAU 0.01
param save
```

悬停 30 s。看 `adrc_status`：

- `z3` 是否稳定在 ±30 以内（不碰自动限幅）？
- `y` 是否比原始角速率平滑？
- `u` 是否还有 2~3 Hz 抖动？

如果还有抖动：`TAU` 往 0.03 加；再不行才用 `NF` 对准谐振峰。

### 第 4 步：逐步放开带宽

每次只加一项，每一项悬停确认后再动下一个：

1. `ESO_W` → 12 → 15 → 18（上限：抖动出现前）；
2. `CW` → 5 → 6 → 8（上限：跟手够了或开始抖）；
3. `FF` → 0.2 → 0.4 → 0.6（恢复打杆跟手，不碰 CW）；
4. 若悬停有漂移/静差，`KI` → 0.1 → 0.2。

### 第 5 步：对比 PID 判定胜负

同航线同环境各飞一组（PID 一组、ADRC 一组），对比：

- 悬停 RMS 角速率（平滑度，目标：不差于 PID）；
- 打杆后回到悬停的收敛时间（跟手）；
- 阵风/侧风下姿态偏差（抗扰，目标：优于 PID）；
- 控制量能量 `actuator_controls_status.control_power`（抖动成本）。

## 6. b0 标定（回顾 + 日志法）

见 `calibrate_b0.py`，三种方法：

1. **静力矩法**：机臂长 a（m）、惯量 I（kg·m²）估算 `b0 = 4·T_motor·a / (I·U_max)`；
2. **阶跃法**：解锁后打一个已知扭矩阶跃，从角速率响应斜率反推；
3. **日志辨识法**：用悬停/机动日志做最小二乘拟合 `ẇ ≈ b0·u`。

66 cm 轴距（B2B 对角 0.66 m，半臂 a = 0.233 m）、3.5 kg、T14×5.5：`b0_roll/pitch ≈ 88~91`，`b0_yaw ≈ 8`。

## 8. v3 更新（2026-08-13）：参考 FMT / Jiachi Zou 论文 / AP_ADRC 的迭代

### 8.1 新增两项真机旋钮

**① 扰动补偿系数 `ADRC_*_GAMMA`（默认 1.0，范围 0~2）**

控制律从 `u = (u0 - z3)/b0` 改为 `u = (u0 - gamma*z3)/b0`。

- 来源：FMT（阿木）ADRC 与 Jiachi Zou 2018 论文——实测中发现**完全补偿总扰动在
  观测噪声 + 执行器延时下会导致不稳定甚至震荡**，引入补偿系数降低补偿比例可提高鲁棒性。
- 真机用法：目前 2.4~3 Hz 极限环，先把 gamma 降到 0.6~0.7（比继续降 CW/ESO_W 更对症），
  稳了再逐步回 0.8~0.9。代价是抗扰/抗风略降。
- 单元测试验证：gamma=1/0.5/0 时稳态跟踪误差 0 / -0.0227 / -0.0455，单调符合预期。

**② 设定值平滑 `ADRC_*_SPS`（默认 0=关，Hz）**

对速率设定值做一阶低通（“贫民版 TD”），平滑打杆阶跃，误差与前馈都用平滑后的参考。

- 来源：AP_ADRC / 无名科创 / ACFLY 的 TD 安排过渡过程思想，简化为 LPF 避免参数爆炸。
- 真机用法：打杆就晃/炸机时开 5~10 Hz，先压住阶跃激励，再谈恢复跟手（配合 FF）。
- 单元测试验证：SPS=5Hz 时阶跃第 10 拍参考为 0.28（未平滑为 0.5），稳态收敛到 0.5。

### 8.2 调试字段扩展

`msg/AdrcStatus.msg` 新增：

- `z3raw[3]`：z3 限幅前的原始值——`listener adrc_status` 看到 `z3raw != z3` 就说明 ESO 顶到限幅，应优先降 ESO_W 或调 gamma；
- `sp[3]`：实际送入控制器的设定值——SPS 开启时能看到平滑轨迹，未开启时等于原始设定值。

## 10. v4 更新（2026-08-14）：三阶增广 ESO + 控制分配器饱和反馈

真机日志（log_211/212/213）确认：三份日志的晃动都是**级联失稳**——ADRC 等效速率增益 `wc/b0 = 0.03~0.04` 只有 PID（0.15）的 1/4，内环比外环（姿态环 P=5.65）还慢，姿态环在 1.5Hz 自激。根因不是 ESO 噪声，是**带宽被压到必失稳区间**。要恢复带宽，必须把 v2/v3 硬化项真正用起来（TAU/γ/FLT 就是为"高带宽不激振"设计的）。本轮在此基础上做了两处**结构级**升级：

### 10.1 三阶增广 ESO（替代"滤波 u 喂 ESO"的近似延时补偿）

**原理**：v2 的 TAU 是"把 u 经过一阶滞后再喂进 2 状态 ESO"——延时没有进观测器状态，只是输入整形。v4 把执行器延时直接建模为观测器状态：

```
植物模型:  tau * x_a_dot = u - x_a        (执行器, x_a = 实际扭矩)
           rate_dot    = b0 * x_a + f     (f = 总扰动)
观测器:    z1 = 角速率, z2 = 执行器扭矩状态, z3 = 总扰动
           z1_dot = b0*z2 + z3 - beta1*e
           z2_dot = (u - z2)/tau - beta2*e
           z3_dot = -beta3*e
增益(极点配置到 -wo):  beta1 = 3wo - 1/tau
                       beta2 = (3wo^2 - beta1/tau - tau*wo^3)/b0
                       beta3 = tau*wo^3
```

- **触发条件**：LADRC 模式且极点配置增益全部为正。β1>0 ⟺ `3·ESO_W·TAU > 1`；β2>0 ⟺ `ESO_W·TAU < 1`（可证 `β2·TAU²·b0 = (1−ESO_W·TAU)³`），即生效带为 **1/3 < ESO_W·TAU < 1**。带外 β2 趋零/变负：z2 校正通道退化或反号，条件积分会在顶轨时"顶住不放"。任一不满足自动回退 v2 输入滞后滤波，**完全向后兼容**；
- **效果**：观测器不再把执行器延时误判成扰动去补偿——这正是 2~3Hz 极限环的激励源。延时进了状态，z3 只含真实扰动；
- 参数不变：仍用 `ADRC_*_TAU`（s）。注意：增广模式有上下界——TAU=0.02 时 ESO_W 建议 ≥ 20（3·20·0.02=1.2>1）且 < 50（ESO_W·TAU<1）；
- `adrc_status.ueso[i]` 在增广模式下显示执行器扭矩状态估计 z2（不再是滞后滤波状态）。

### 10.2 控制分配器饱和反馈（对齐原版 PID 的反饱和）

原版 PID（`MulticopterRateControl.cpp`）读取 `control_allocator_status`，在力矩饱和时冻结积分方向。v4 给 ADRC 补上同等机制，并做了 ADRC 特有增强：

1. **积分反饱和**：分配器报某轴力矩没达成（`torque_setpoint_achieved=false` 且 `unallocated_torque[i]≠0`）时，LADRC 积分不再向饱和方向积分（镜像原版 `RateControl::updateIntegral` 的方向钳制），叠加原有的输出钳位条件积分；
2. **ESO 输入反饱和（ADRC 特有，更重要）**：分配器饱和时，把**实际达成扭矩**（指令 − unallocated）喂给 ESO，而不是指令值——否则 ESO 会把"分配器没给出力矩"当成扰动去补偿，z3 持续积分，比积分器绕环更危险。电池缩放开启时按缩放系数还原到控制器单位；
3. 该机制**始终开启**（无新参数），只在真实饱和时起作用，正常飞行零影响；
4. 顺带修正：`resetIntegral()` 现在同时清 z3 和 `_integ`；`rate_ctrl_status.rollspeed_integ` 改为发布 z3（总扰动估计，ADRC 的"积分等价物"）。

### 10.5 执行器饱和直接建模进增广 ESO 状态（2026-08-14 追加）

v4 增广 ESO 的执行器状态 z2 是显式状态，因此可以把"执行器饱和"这个非线性**直接建模进观测器**——这是滞后滤波（v3）结构上做不到的：

- **饱和积分器建模**：执行器输出扭矩物理上有界 [-1,1]。z2 更新改为**条件积分（anti-windup）**：z2 顶到轨线且驱动力（指令 + 观测器校正 β2·e）继续推挤时，保持状态而非积分多余部分。盲钳位（clamp-after-integration）会把未钳位的 z2（1+h·ẑ₂）先喂给 z1 更新再钳位，顶轨期间 z1 被虚增驱动——条件积分保持 z2=轨线，z1 不被虚增，消除该伪影；
- **诚实验证结论**：在"持续饱和 + b0 失配 + 释放"场景下对比，条件积分与盲钳位的闭环轨迹**逐位相同**（max diff = 0）。原因：指令在进 ESO 前已被 `applyLimits` 钳位，且 §10.2 的分配器反馈已把"实际达成扭矩"喂给 ESO——两条主饱和路径都被更早的环节覆盖了；且该场景顶轨时速率达到平衡、e→0、校正项为零，这正是盲钳位与条件积分唯一可能分叉的条件。若 b0 失配下速率仍在变化（e≠0），两者会分叉，条件积分是正确的那一个。所以这一步是**数学正确性/鲁棒性**改进，不是性能改进，也不解决悬停问题；
- **已否决的启发式**：曾尝试"顶轨时把 z3 积分减速 ×0.2"（缓解 b0 失配被 z3 当扰动累积），验证显示速率恢复完全不变、z3 退绕反而更慢，已删除——不引入无证据的魔数；
- **结构意义**：z2 带饱和模型后，后续可把执行器限速、ESC 动态、桨效曲线等更多非线性依次建模进状态——这是增广 ESO 相对"滞后滤波"唯一的结构性优势，也是它存在的理由；
- 调试：增广模式下 `adrc_status.z2[i]` 直接显示执行器扭矩状态，顶轨（±1）时可与 `u` 对比判断是否真实饱和。

**与 §10.1/10.2 一致的总预期**：观测器侧的这些改进都是"正确性 + 地基"，真机悬停晃动的解药仍在参数层（§10.4 的带宽 + 硬化配对）。

### 10.6 真机前迭代（2026-08-14 追加）

真机测试前一轮审查 + 修复（对应代码 `Adrc.cpp` / `Adrc.hpp` / `AdrcRateControl.cpp`）：

- **增广 ESO 生效带收紧**：新增 `Adrc::augmentedEsoEnabled()`，触发条件从 `3·ESO_W·TAU > 1` 收紧为 **1/3 < ESO_W·TAU < 1**（即 β1>0 且 β2>0）。β2 的符号与 (1−ESO_W·TAU) 相同，带外 z2 校正退化/反号，条件积分行为反转；收紧后自动回退 v3，向后兼容不变；
- **yaw 生效范围**：§10.4 已补充——推荐 yaw 参数不触发增广 ESO（乘积≈0.4~0.7 在带外），yaw 走 v3 路径；

真机判据不变（§10.4）：先确认 `adrc_status.z2` 在增广生效时随 u 变化、`ueso == z2`，再按带宽阶梯上调。
